# AGENTS.md

适用于 `ddl/` 及其数据库方言子目录。ORM 映射规则见 `internal/models/AGENTS.md`。

## 目录职责

本目录保存数据库 schema 变更 SQL。按数据库方言分目录，文件名使用可排序版本前缀；DML 和业务 seed
数据放在 `dml/`。

## 修改约束

- 已部署版本的 DDL 默认视为历史 artifact；修正线上结构时新增后续版本脚本，不静默改写已执行脚本。
- 表、字段、索引、约束、默认值和 nullable 必须与 ORM model、DAO 查询及测试 fixture 一致。
- 使用目标方言支持的语法，不把 PostgreSQL partial index 等特性复制到其他方言目录。
- 每次变更说明升级顺序、历史数据处理、锁表/重写风险、失败回滚和多版本应用兼容窗口。
- 新增非空列、唯一约束或索引前评估现有数据冲突、回填成本和线上锁风险。
- 不包含真实业务数据、凭据、生产连接信息或不可审计的手工修复语句。

## 验证重点

- 在隔离数据库中演练升级；涉及回滚时同时演练回滚或明确不可逆原因。
- 同步运行相关 ORM / DAO 测试，并检查 SQL 文件与 `internal/models/` 的字段 contract。
