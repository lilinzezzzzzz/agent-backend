# AGENTS.md

适用于 `ddl/` 及其数据库方言子目录。ORM 映射规则见 `internal/models/AGENTS.md`。

## 目录职责

本目录保存数据库 schema SQL。按数据库方言分目录；当前脚手架使用 `init.sql` 表达完整初始 schema，DML 和业务
seed 数据放在 `dml/`。

## 修改约束

- 当前项目是未部署脚手架，schema 调整直接更新最新基线 DDL，不为历史数据新增升级、回填或兼容脚本。
  只有任务明确面向已存在环境时，才将已部署 DDL 视为历史 artifact 并新增后续版本脚本。
- 表、字段、索引、约束、默认值和 nullable 必须与 ORM model、DAO 查询及测试 fixture 一致。
- 使用目标方言支持的语法，不把 PostgreSQL partial index 等特性复制到其他方言目录。
- 面向已存在环境的变更才需要说明升级顺序、历史数据处理、锁表/重写风险、失败回滚和多版本应用兼容窗口。
- 面向已存在环境新增非空列、唯一约束或索引前，评估数据冲突、回填成本和线上锁风险。
- 不包含真实业务数据、凭据、生产连接信息或不可审计的手工修复语句。

## 验证重点

- 基线 DDL 在隔离数据库中验证可直接建库；只有增量 DDL 才演练升级和回滚。
- 同步运行相关 ORM / DAO 测试，并检查 SQL 文件与 `internal/models/` 的字段 contract。
