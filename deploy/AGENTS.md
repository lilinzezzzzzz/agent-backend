# AGENTS.md

`deploy/` 保存部署适配资产；`deploy/journald/` 提供宿主机持久化配置示例。根规则同时将本文件作为
`Dockerfile`、`compose.yaml` 和 `.env.compose.example` 变更的配套约束。

- 镜像基础版本和关键运行依赖固定版本；变更来源或 digest 时说明供应链和兼容性影响。
- 宿主机配置不由 Compose 或验收脚本自动安装；应用前检查现有配置、磁盘预算并取得相应授权。
- journald 固定服务标签使用项目、环境和服务身份，不包含容器 ID 或版本。
- Compose 参数与应用 TOML 配置分离；不把部署变量扩展成应用配置环境变量，不把 `.secrets` 打入镜像。
- 镜像继续使用已有虚拟环境及显式进程入口；配置/密钥只读挂载且缺失时失败，不自动创建空配置文件。
- 保留策略与部署文档一致，明确整机共享预算、限流及跨发布历史边界。
- 不引入真实凭据、隐式生产主机依赖或运行时下载的未锁定内容；不清理旧部署文件、volume 或 journal。
- 持久化、容器删除后的历史查询及导出需在隔离 Linux 环境验证；本地静态检查不能证明运行时行为。
- TCP healthcheck 只证明端口可连接；不能据此声称数据库、模型、业务就绪或主机重启恢复已验证。
