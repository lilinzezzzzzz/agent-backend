# AGENTS.md

`deploy/` 保存部署适配资产；`deploy/journald/` 提供宿主机持久化配置示例。

- 镜像基础版本和关键运行依赖固定版本；变更来源或 digest 时说明供应链和兼容性影响。
- 宿主机配置不由 Compose 或验收脚本自动安装；应用前检查现有配置、磁盘预算并取得相应授权。
- journald 固定服务标签使用项目、环境和服务身份，不包含容器 ID 或版本。
- 保留策略与部署文档一致，明确整机共享预算、限流及跨发布历史边界。
- 不引入真实凭据、隐式生产主机依赖或运行时下载的未锁定内容；不清理旧部署文件、volume 或 journal。
- 持久化、容器删除后的历史查询及导出需在隔离 Linux 环境验证；本地静态检查不能证明运行时行为。
