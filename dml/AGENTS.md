# AGENTS.md

适用于 `dml/`。数据库 schema 变更放在 `ddl/`。

## 目录职责

本目录保存可审计的初始化数据、参考数据或数据修复 SQL，不保存应用运行时查询。

## 修改约束

- 新脚本使用可排序版本名，明确目标数据库方言、前置 schema 版本、执行顺序和适用环境。
- 可重复执行的 seed 优先使用明确的幂等键或冲突处理；一次性修复必须说明重复执行后果。
- 大批量更新、删除或回填要分批、限制范围并说明锁、事务日志、失败恢复和回滚方案。
- 不提交生产导出数据、个人信息、真实账号、token、密钥或环境专属连接信息。
- DML 改变枚举、状态或系统内置数据时，同步检查代码常量、schema、缓存和测试 fixture。

## 验证重点

- 只在隔离数据库或明确的测试 fixture 中演练，不对共享或生产数据库运行。
- 验证首次执行、重复执行和失败回滚后的数据状态。
