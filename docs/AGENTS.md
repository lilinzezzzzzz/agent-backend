# AGENTS.md

适用于 `docs/`。本目录 README 是人类文档索引，不因存在本文件而删除。

## 目录职责

`docs/` 保存架构、设计、运行手册和开发指南，按主题目录归档。计划文档的额外约束见
`docs/plans/AGENTS.md`。

## 修改约束

- 新文档放入最接近的主题目录；只有真正跨主题的文档才保留在 `docs/` 根目录。
- 新增、移动、重命名或删除文档时同步更新 `docs/README.md` 和所有相对链接。
- 明确区分当前实现、目标设计、历史记录和未验证建议；当前行为以代码、配置、schema 和测试为准。
- 路径、命令、配置 key、API 字段和状态值使用仓库中的真实名称，不复制容易漂移的大段实现。
- README 面向使用者解释背景、流程和操作；AGENTS.md 只记录未来修改必须遵守的约束，两者不互相替代。
- 不写入真实密钥、内网敏感信息、生产数据或无法维护的“最后更新”元数据。

## 验证重点

- 检查标题层级、代码围栏、相对链接、文件名和索引。
- 文档声称命令或测试通过时，必须保留实际执行证据和适用环境。
