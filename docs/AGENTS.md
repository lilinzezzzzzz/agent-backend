# AGENTS.md

`docs/` 保存架构、设计、运行手册和开发指南；当前行为以代码、配置、schema 和测试为准。

- 文档区分当前实现、目标设计、历史记录和未验证建议；引用权威来源，不复制易漂移的大段实现。
- 新增、移动或删除文档时更新受影响的索引和相对链接；不添加无人维护的“最后更新”元数据。
- `docs/plans/pending/` 保存未完成计划，`completed/` 只保存实现和验证均有证据的历史计划。
- 计划状态、checklist 和验证结论必须与仓库事实一致；废弃计划标记替代方案，已完成计划不回写成当前设计。
- 文档中的命令、路径、配置 key 和 API 字段使用仓库真实名称；声称已验证时注明实际范围和环境。
- 不写入真实密钥、生产数据或敏感内部信息。
