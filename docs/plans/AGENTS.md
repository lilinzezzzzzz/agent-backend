# AGENTS.md

适用于 `docs/plans/`。通用文档约束见 `docs/AGENTS.md`。

## 归档规则

- `pending/` 保存尚未执行、实施中、待验证或待拆分的计划。
- `completed/` 保存实施完成且记录了验证结论的历史计划。
- 目录内 README 负责索引，计划状态、文件路径或标题变化时必须同步更新。

## 修改约束

- 计划必须区分目标、非目标、当前事实、实施步骤、完成门槛、验证、风险和回滚；不强制机械套用
  固定标题。
- 阶段状态以仓库实现和实际验证为证据；没有证据时不得标记“已完成”或勾选 checklist。
- 从 `pending/` 迁入 `completed/` 前，同步更新状态摘要、Phase 进度、验证记录和 Definition of Done。
- 已完成计划是历史决策记录。后续实现演进应链接当前设计文档，不回写历史目标造成时间线
  混淆。
- 失效计划应明确标记为已废弃并链接替代方案，或在确认无审计价值后删除；不要保留两个并列
  事实来源。
- 移动计划时修正其内部相对链接、文档索引和仓库内引用。

## 验证重点

- 检查索引无断链、章节引用正确、代码围栏成对、状态与 checklist 一致。
- 验证命令和结果必须注明实际执行范围；外部依赖失败与通过项分开记录。
