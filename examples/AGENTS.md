# AGENTS.md

适用于 `examples/`。

## 目录职责

本目录保存可独立运行的演示代码，不作为生产 entrypoint 或公共包 contract。示例应优先解释一个能力，
避免复制完整业务架构。

## 修改约束

- 示例必须明确启动方式、外部服务、端口和凭据前置条件；默认绑定 loopback，不暗示可直接生产部署。
- API key 只从显式环境变量读取，不硬编码、回显或提交真实值。
- 邮件、支付、删除等外部副作用默认使用 mock；改为真实操作前必须增加清晰开关和用户确认。
- LLM / MCP tool 参数视为不可信输入；保持结构化校验、未知工具处理、循环上限和错误边界。
- 示例可以为教学保持局部实现，但不要让生产代码反向依赖 `examples/`。
- 修改外部 SDK 用法时以当前锁定依赖和官方 contract 为准，并标明示例是否实际运行验证。

## 验证重点

- 无网络路径优先做 import、语法和静态检查。
- 真实 LLM / MCP 调用只在显式凭据和本地测试服务可用时运行，结果不得泛化为生产兼容性。
