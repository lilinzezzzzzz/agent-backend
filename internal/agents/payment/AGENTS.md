# AGENTS.md

`internal/agents/payment/` 是只读和纯计算的支付支持 Agent，不执行资金或账户副作用。

- 工具只做参数解析、确定性计算和 `RagService` 调用，不直接访问数据库、Redis、支付渠道或用户凭据。
- 支付规则、知识检索和金额计算必须经过工具；缺少参数或工具失败时模型不得猜测结果。
- 金额使用非负整数分，优惠不得超过商品加运费，不使用 float 或 LLM 结果作为权威金额。
- 真实支付、扣款、退款、解绑或账单修改必须由独立 Workflow 处理权限、幂等、事务、回调验签和补偿。
- 工具参数、路由范围或副作用边界变化时同步 README、Service、API schema 和测试。
