# AGENTS.md

适用于 `pkg/lazy_proxy/`。

## 模块职责

本模块提供类型友好的延迟代理，把对象解析委托给调用方 getter；实例缓存、线程安全和生命周期仍由
getter 所属模块负责。

## 修改约束

- 不在代理内部缓存真实对象或吞掉 getter 异常，否则会改变配置、logger、Redis 等调用方的生命周期语义。
- 保持属性访问转发和静态类型返回约定；新增魔术方法前检查是否会意外触发初始化、比较、迭代或
  序列化。
- `repr` 等诊断路径不得泄露代理对象中的 secret，也不应把未初始化状态伪装成可用对象。
- 不依赖 `internal/`，不在 import 时调用 getter。

## 验证重点

- 覆盖延迟解析、重复访问、getter 异常、未初始化 repr 和类型相关调用方。
