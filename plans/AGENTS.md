# AGENTS.md

`plans/` 维护实施与验收状态；目录导航由本目录及 `pending/`、`completed/` 的 README 维护。

- 未执行、实施中或仍有必需验证缺口的计划留在 `pending/`；代码已落地不等于计划已完成。
- 只有实现与要求的验证都有证据后才迁移到 `completed/`；迁移时同步索引、相对链接和引用方。
- checklist 的每个完成项对应可核对结果；分别记录本地静态检查、单元/SQLite、真实 PostgreSQL、
  外部服务与部署验收，跳过或未运行的检查保持明确，不能用一种证据代替另一种。
- 当前行为与设计目标分开描述；以实际代码和验证校准状态，不从计划中的勾选推断实现。
- 已完成计划保留历史方案和当时证据；后续替换只补充废弃/替代说明及链接，不将历史正文改写成当前设计。
- 废弃的 pending 计划说明原因及替代方案，避免保留多个看似有效的实施入口；不擅自删除有审计价值的历史记录。
